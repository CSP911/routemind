# Processing a court order when it arrives

## Steps

1. Log the order against the employee record, noting the court, case number, and creditor.
2. Confirm the employee's identity matches the order exactly — name and resident registration number, not name alone.
3. Calculate the protected portion for the current month's wage using the band table, before applying any deduction.
4. Set up the garnishment line on the deduction side and route the withheld amount to the named account.
5. Keep the order open until the court or creditor notifies satisfaction, or the order's own end date is reached.

## What doesn't happen

The employee's manager is not notified, and the employee is not asked to agree to the deduction — the order itself is the authority.

**Payroll must begin withholding from the first payslip it can still adjust after the order is received, not from the first payslip after the employee is informed.** Waiting for that conversation is a common way to fall behind the required start date.

Missing that start date has a cost of its own, separate from the deduction itself.
