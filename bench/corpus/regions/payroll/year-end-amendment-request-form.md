# What an amendment request to payroll must include

Adding or correcting a deduction after the original submission needs a specific request, not just a note to the payroll desk.

## Required fields

| Field | What it must show |
|---|---|
| Employee ID and name | Matches the original year-end submission |
| Item type | Which deduction or allowance is being added or corrected |
| Amount | The corrected figure, not the difference |
| Evidence reference | Document number or receipt attached to the request |
| Date and signature | Confirms the employee is requesting the change |

**A request submitted without its evidence reference attached is returned unprocessed — it does not sit in a queue waiting for the missing document.** The employee has to resubmit from scratch, which can push the request past the internal cutoff if it happens late in the window.

The process this form feeds into, including what payroll does with it once accepted, is covered separately.
