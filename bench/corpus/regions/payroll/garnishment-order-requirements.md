# What a court order must state

Payroll checks every incoming order against a fixed list before setting up a deduction line. An order missing any of these is returned to the sender, not held pending clarification.

## Required details

| Field | Why it's checked |
|---|---|
| Issuing court and case number | Identifies the order and lets payroll confirm it's genuine |
| Employee's full name and resident registration number | Matches the order to the correct HR record |
| Creditor name and payment account | Where the deducted amount is sent |
| Amount or percentage sought | Sets the cap on what's deducted, above the protected portion |
| Effective date | Fixes which payslip the deduction starts on |

**An order without a matching resident registration number is returned unprocessed, not actioned on the name alone.** Two employees can share a name; payroll does not guess which one the court means.

Once an order clears this check, it moves straight into the standard receipt procedure.
