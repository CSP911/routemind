# Bonus tax withholding by type

Not every bonus goes through payroll's tax engine the same way. The method depends on what kind of bonus it is, not on the amount.

## The three methods

| Bonus type | Withholding method | Note |
|---|---|---|
| Performance bonus (KPI-based, variable) | Annualized withholding method | Recalculated against year-to-date income, per the usual bonus withholding run |
| Fixed/regular bonus (contractual, on a set date) | Annualized withholding method | Same recalculation, even though the date never moves |
| Signing bonus (one-off, not tied to KPIs) | Flat rate election available | Payroll can apply a single flat rate instead, if elected before payment |

## Making the election

The flat-rate option only applies to the signing bonus, and only if payroll receives the request in writing before the payment date. Once the amount has gone through the annualized method, it cannot be switched over afterward — there is no second run to move it into.

**Electing the flat rate does not change what is finally owed.** It only changes how the estimate is calculated during the year. Like every other bonus, the amount withheld here is provisional — it gets settled against actual annual income the following February, same as any other bonus line.
