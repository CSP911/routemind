# The withholding start deadline

Once a garnishment order passes the document check, payroll must begin withholding from the first payslip it is still able to adjust — normally the next scheduled run, and no more than one pay cycle after the order is confirmed valid.

## What happens if it's missed

The deadline is not a courtesy to the creditor. Failing to withhold on time does not just delay the money reaching them.

**Missing the withholding start date can make the company itself liable to the creditor for the amount that should have been withheld** — separately from whatever the employee still owes. This is why an order lands with the same urgency as a payslip correction, not as paperwork to file for later.

Once withholding starts, it continues on the same schedule as any other deduction line until the court or creditor closes the order out.
