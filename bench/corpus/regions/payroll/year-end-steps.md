# Year-end tax settlement

1. **Mid-January**: download the pre-filled data from the tax office service (most items are there).
2. Gather what the service does not show — rent, glasses, school uniforms, donations, overseas tuition,
   some medical costs.
3. Check dependants. **Claiming a relative over the income or age limits** leads to a clawback later.
4. Upload it in the groupware year-end menu → see the deadlines.
5. It lands in **February's pay** as a refund or an additional deduction.

| Commonly got wrong | |
|---|---|
| Both parents claiming the same child | Only one may. Both get clawed back |
| Siblings each claiming a parent | Only one may |
| The rent deduction | Requires the address to be registered |
| Counting tax-free pay as income | Tax-free lines were never taxable in the first place |
