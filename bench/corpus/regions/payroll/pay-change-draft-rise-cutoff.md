# Draft rise vs cut-off

A pay review recommendation can be approved in draft weeks before payroll ever sees it. Draft approval is a decision by the reviewer, not an instruction to payroll — nothing changes on a payslip until sign-off clears payroll's own cut-off.

## What each state does

| State | What it means | Payroll action |
|---|---|---|
| Draft | Recommended, not yet signed off | No change; existing figure continues |
| Signed off before cut-off | Confirmed instruction received in time | New figure applies from that month's payslip |
| Signed off after cut-off | Confirmed instruction received late | New figure applies from the following month's payslip |

## Why the gap matters

A draft can carry an intended effective date — the month the reviewer meant the rise to start. **Payroll does not use that date. It uses the date sign-off actually clears the cut-off**, which can land a full cycle later than the draft intended.

If the intended date has already passed by the time sign-off clears, the shortfall isn't backdated into the draft. It lands as a single retroactive lump on the next payslip, calculated the same way any other back-dated rise is.
