# Payroll desk

| | |
|---|---|
| Owns | Running pay, social insurance enrolment and settlement, year-end settlement, leaving pay, withholding |
| Reach | Ext. 2150 (Corporate support) |
| Pay day | The 25th (the preceding working day if it falls on a holiday) |
| Queries close | Only items received **by the 15th** reach that month's pay |

- Pay is not calculated until attendance closes (the 3rd of the following month).
- Payslips are visible to you alone in the groupware; there is nothing to request a copy of.
- If an amount looks wrong, **compare the payslip lines against attendance** before asking.
