# When the same expense is paid twice

Payroll's monthly reconciliation checks each category against its assigned mechanism. Occasionally a claim for actual cost is submitted under a category that already has a standing allowance running — a new hire mid-switch, or a claim filed before the mechanism was confirmed. Both payments would otherwise land on the same payslip.

## What payroll does

| Situation | Action |
|---|---|
| Allowance and reimbursement claim both submitted for the same category, same month | Reimbursement claim is held pending a category check |
| Category confirmed as allowance-based | Reimbursement claim rejected; employee redirected to the next switch cycle |
| Category confirmed as reimbursement-based | Allowance line reversed on the same payslip; reimbursement stands |

## The tax trap

**Paying both does not make the second payment tax-free by association.** The nontaxable treatment covers one real cost once. If a fixed allowance has already been paid against a category, a reimbursement claim for the identical expense is treated as topping up income already covered — it's added to gross pay as taxable, not routed through the tax-free reimbursement path a second time. Only the allowance keeps its exempt status.

This sits one level above claiming a nontaxable allowance and separately expensing the same receipt — that's double counting inside one mechanism, not an overlap between the two.
