# Switching an allowance to a reimbursement claim

An employee or manager can ask payroll to move a category — own-car use, say — from a standing monthly allowance onto actual-cost reimbursement, or back again. The mechanism is fixed per category at setup, so a switch has to be requested before it takes effect; it cannot be applied to a month payroll has already processed.

## Steps

| Step | Who | Deadline |
|---|---|---|
| Submit switch request with reason | Employee or manager | Before payroll's monthly cut-off |
| Confirm no open claim exists under the old mechanism | Payroll | Same cycle |
| Update the category flag on the employee's record | Payroll | Before the next run |
| New mechanism appears on payslip | Payroll | Following month |

## Effective date

The switch takes effect on the next payslip, not the one already in progress. **A request submitted mid-month does not cancel that month's allowance** — the standing allowance still runs at its full scheduled value for the current cycle, and the new mechanism only starts the month after. Employees expecting an immediate change should be told the timing up front, before they stop keeping receipts they'll still need.

Whichever mechanism is running, the underlying cap and evidence rules for that category don't change — only which side of the payslip carries the payment.
