# Post-leaving exercise window

## The window
Vested stock options must be exercised within 90 days of the last active day. Options not exercised inside that window lapse permanently — there is no extension, and no reinstatement once the window closes.

| Award already vested at leaving | What happens |
|---|---|
| RSUs / performance shares | Already issued as shares; unaffected by leaving |
| Stock options | Must be exercised within 90 days, or they lapse |

## What doesn't change the count
The 90 days run from the last active day, the same date used for severance and leave payout, not from the date final pay is issued or the date the leaving paperwork is signed off.

**Missing the window forfeits value the employee already earned, not just an opportunity.** A vested, in-the-money option that isn't exercised by day 90 is gone entirely — payroll does not reopen it, and there is no clawback-style correction available afterward.

Whether the exercise itself creates a tax event separate from any gain at sale is covered under vesting versus sale tax.
