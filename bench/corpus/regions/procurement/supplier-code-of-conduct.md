# Supplier code of conduct

Every vendor registered above the lowest approval band (500,000 KRW and over) must sign the supplier code of conduct before their first purchase order is placed. Below that band it is encouraged but not enforced.

## What it covers

- No child or forced labour anywhere in the supply chain
- No facilitation payments or off-book commissions to staff
- Basic workplace safety standards at the supplier's own site
- Cooperation with a due diligence re-check if one is requested

## Renewal

| Event | Requirement |
|---|---|
| First registration | Signed code filed with the vendor form |
| Annual, while active | No re-sign required unless the code text changes |
| Code text changes | All active vendors re-sign within 60 days |

**The code is signed once per vendor, not once per contract.** A vendor with three separate purchase orders running does not sign three times — but if they refuse the annual re-check itself, that refusal is treated as a fresh disqualification event, not a lapse that quietly expires.

A refusal to sign, like a sanctions hit, feeds into the disqualification list below.
