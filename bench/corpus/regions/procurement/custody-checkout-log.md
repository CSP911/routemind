# The custody checkout log

Every borrow of a signed original is recorded in this log before the document leaves GA's cabinet.

| Field | Captures |
|---|---|
| Contract ID / vendor | Which original is going out |
| Borrower name and team | Who is accountable for its return |
| Date out | When custody transferred |
| Expected return date | The date the borrower commits to |
| Actual return date | Filled in by GA on physical return |
| Purpose | Why it was needed |

## The trap

**Leaving the expected return date blank is not the same as an open-ended loan.** GA treats a blank field as immediately overdue, not as flexible — the borrower has to write a real date, even a placeholder one, or the entry starts flagging on the first daily review.

The return deadline itself, and what happens if it lapses, is covered in the borrowing procedure.
