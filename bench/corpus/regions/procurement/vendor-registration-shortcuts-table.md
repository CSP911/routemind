# Vendor registration shortcuts by case

Five situations change one piece of the standard registration file. None of them remove the vendor form itself, and none of them skip screening.

| Case | What's swapped | Still required |
|---|---|---|
| Sole trader | Individual business registration certificate instead of a corporate one | Vendor form; account in the trader's own name |
| Overseas supplier | Certificate of incorporation or tax residency certificate | Sanctions and 25%+ beneficial owner screening |
| Mismatched account | Nothing — held until resolved | Account name identical to the certificate |
| One-off purchase | Code of conduct waived only if under 500,000 KRW | Vendor form and certificate at any amount |
| Supplier withholds papers | Nothing — no vendor record until received | Full file before any purchase order |

**Nothing on this table lowers the bar; each row only changes which document satisfies it.** The certificate can change shape, the account can be personal or corporate, but the file is either complete or the purchase order does not issue — the band-reference table decides who signs off once it is.
