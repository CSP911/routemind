# Return notice by leave of absence category

## The notice each category needs

| Category | Notice before return |
|---|---|
| Study leave | At least 14 days before the planned return date |
| Military service leave | Confirm within 7 days of the discharge date |
| Family care leave | At least 14 days before the planned return date |
| Unpaid personal leave | At least 14 days before the planned return date |

## Why military leave runs differently
Three of the four categories give the employee a fixed leave period, so the standard 14-day return notice works the same way it does for other planned absences. Military service leave does not — the discharge date is set by the service branch, not agreed in advance, so there is nothing to give 14 days' notice against.

**Applying the 14-day rule to a military discharge is the mistake — HR needs confirmation of the actual discharge date within 7 days after it happens, not a notice period counted backward from a date nobody controls.** The reinstatement duty that follows is covered under military leave itself.

The same 14-day pattern is also used for an early return from parental leave.
