# Same-morning leave requests

## The procedure
1. Contact the manager directly — by phone or message — before the normal start of the working day, or as soon as possible if the need arises after start of day.
2. Get a verbal or written yes from the manager.
3. Enter the request in the leave system the same day, selecting the correct date and unit (full day, half day or quarter day as appropriate).

## The trap
**A same-morning leave verbally approved by a manager but never entered into the system by the end of that day is not recorded as leave — it shows as an unexplained absence.** Verbal approval only covers the immediate decision to let someone stay away; the system entry is what actually converts it into a leave day against the balance.

## Responsibility
Entering the record same-day is the employee's responsibility where possible; if they are unreachable, the manager can enter it on their behalf, but it should not be left open past the day itself.

Cancelling a same-morning request once entered follows the same rule as any other cancellation — before the day starts, not after.
