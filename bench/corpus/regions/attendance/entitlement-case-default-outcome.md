# What happens when an entitlement case is never filed

## Default treatment
| Case type | If nobody files it |
|---|---|
| Group transfer | Treated as a new joiner — 15 days, no prior service |
| Rehire | Treated as a new joiner — 15 days, no prior service |
| Leave of absence | Service clock still runs — this one doesn't need filing to take effect |
| 3/5/7-year milestone | Applies automatically — no filing needed |
| Final balance (leaver) | Calculated from whatever service and usage the system already has on record |

## The trap
Two of the five cases are genuinely silent: leave-of-absence continuity and the milestone bump both run off the service-start date without anyone submitting anything. But **transfer and rehire are not silent — if nobody tells HR, the system has no way to know a prior service history exists, and it will default to first-year treatment.** This surprises people who assume their group company history is "on file somewhere" simply because both companies use the same HR system.

If a case looks like it should have applied automatically and hasn't, check whether it was one of the two that don't need filing, or one of the three that do.
