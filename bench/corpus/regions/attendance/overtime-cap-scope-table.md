# What counts toward the 12-hour weekly cap

The weekly overtime cap is a single limit, not one limit per hour type. Everything logged as overtime in a week, whatever premium it carries, is added to the same running total.

## Scope

| Hour type | Counts toward the 12-hour cap |
|---|---|
| Ordinary overtime | Yes |
| Night hours | Yes |
| Holiday hours | Yes |

There is no separate allowance for night or holiday work sitting on top of the 12 hours. A week that has already logged 10 ordinary overtime hours has only 2 hours of headroom left, regardless of whether the remaining request falls inside the night window or on a holiday.

**Being inside the correct night or holiday time window does not exempt a request from the weekly total** — the system checks the cap first, and a request that is otherwise perfectly valid under the night/holiday definitions is still rejected outright if the week's total would pass 12 hours.

For the actual premium each hour type is paid at, see the overtime rate table; this page only governs whether the hours are countable in the first place.
