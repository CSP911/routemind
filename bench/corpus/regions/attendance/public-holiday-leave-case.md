# Leave that spans a public holiday

## The case
An employee books Monday to Friday off. Wednesday of that week is a public holiday. Only four days are deducted from the annual leave balance — Wednesday was never a working day to begin with, so it cannot be "used" as leave.

| Day | Leave deducted? |
|---|---|
| Mon, Tue | Yes — 1.0 day each |
| Wed (public holiday) | No |
| Thu, Fri | Yes — 1.0 day each |

## The trap
**Employees sometimes assume a public holiday landing mid-leave should let them extend the booked block by a day at no extra cost, since "the holiday wasn't used." It was never charged in the first place, so there is nothing to reclaim** — the holiday simply falls outside the leave balance calculation at either end of the request.

## Booking around it
If a holiday falls at either end of a requested block, only the working days either side need to be booked; the holiday itself should not be entered as a leave day.

The same logic applies to a trip day that happens to fall on a public holiday, covered under trip attendance.
