# How trip hours are recorded

Every trip day is entered against one of three codes, and the code — not the fact that duty was performed — is what the attendance system uses to decide whether the day affects pay, leave balance, or neither.

| Day type | Duty performed | Code |
|---|---|---|
| Regular working day | Yes | Trip — working day |
| Weekend or holiday | Yes | Trip — non-working duty |
| Weekend or holiday | No (travel/rest only) | Not entered as a trip day |

Only the middle row generates any additional entitlement; the bottom row is ordinary time off that happens to occur while away, and gets no special treatment at all.

**The trap is coding every day of a multi-day trip the same way because the request itself was approved as a single block — each day still has to be coded individually against what actually happened on it.** A five-day itinerary with one quiet Saturday inside it is not a five-day block of "trip — non-working duty."

The weekend trip case above shows this distinction applied end to end.
