# Parental leave cases — where to start

This section covers both parents taking leave at the same time, splitting a leave into two blocks, returning early, extending a block already in progress, coming back to a different team than the one left, and how insurance is billed while someone is out on leave.

## The common case
One parent, one continuous block, a return to the same team — that's the default the other cases are read against. Splitting into two blocks or returning early both change the notice periods involved, not the entitlement itself.

## Where it gets complicated
Both parents on leave at once is handled as two independent cases that happen to overlap, not one combined case — each parent's notice, return date and insurance billing are tracked separately. A return to a different team doesn't reset anything about the leave; it only changes who signs off the return.

**The trap**: extending a block already underway is often submitted as a new leave request instead of an extension, which restarts notice-period counting and can push the return date later than intended.

Once leave closes out, the same person's attendance record folds back into ordinary mid-year joiner logic if the return lands close to a service milestone.
