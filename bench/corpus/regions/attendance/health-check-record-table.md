# What the health check record holds

The attendance system stores the outcome of the annual check, not the underlying medical report. HR receives only the result category; the detailed findings stay with the employee and the provider.

| Field | Who enters it | Visible to |
|---|---|---|
| Date attended | Line manager, from the attendance system | Line manager, HR desk |
| Result category (fit / follow-up required / restricted duty) | HR desk, from the provider's summary | HR desk only |
| Follow-up deadline, if any | HR desk | HR desk, employee |
| Restricted-duty conditions, if any | HR desk, with the line manager | Line manager, HR desk |

A "follow-up required" or "restricted duty" result does not appear on the attendance record as leave or absence — it is a flag on the employee's HR file, separate from any day taken off.

**The line manager sees that the check happened, not what it found.** A manager asking an employee to disclose the result category directly is asking for information the system does not route to them; any accommodation goes through the HR desk instead.

The paid time off used to attend the check itself is recorded as ordinary attendance, not against this result field — covered next.
