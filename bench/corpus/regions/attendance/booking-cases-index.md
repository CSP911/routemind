# Booking cases at a glance

The leave-apply procedure covers a normal request: a full day, booked ahead, with enough balance and no public holiday inside it. Six situations break one of those assumptions, and each is handled by its own rule rather than a special case bolted onto the general one.

## The six exceptions

| Situation | What changes |
|---|---|
| Half or quarter-day booking | Deduction is fractional, approval routing differs |
| Booking cancelled | Balance restoration depends on timing |
| Last week of December | Year-end window and queue priority apply |
| Same-morning request | Approval must happen before the day is recorded |
| Public holiday inside a block | Statutory holidays are skipped, floating ones are not |
| Balance falls short | Request is rejected outright, never partially |

## Where to look

Each row above has its own page covering the mechanics. This page exists only to point you at the right one before raising a ticket for something that already has an answer.

**The general leave-apply procedure assumes none of the six situations above — the moment one applies, stop following it and check the specific rule instead.**

A request that clears all six checks still needs the line manager's approval recorded in the attendance system before it counts as booked.
