# Escalating a stalled trip approval

A trip request that sits with an approver past a fixed point escalates automatically rather than waiting for departure to force the issue.

## The trigger
1. Domestic: if the line manager has not acted within 2 working days of submission, the request escalates to the department head.
2. Overseas: if either the line manager or the HR desk has not acted within 3 working days of submission, the request escalates to the department head or a deputy HR reviewer respectively.

## What escalation does and doesn't do
Escalation adds a second possible approver — it does not reset the approval deadline set for the trip type. **A request that escalates on day 3 still has to clear approval by the same 2- or 5-working-day mark as if it had never stalled.** Escalating buys a different approver, not more time.

## If escalation also stalls
A request that is still pending after escalation and after the approval deadline has passed is treated the same as any other request unapproved at departure — it moves to the late-approval path rather than staying open indefinitely.

Filing that late-approval request itself follows a separate, shorter procedure.
