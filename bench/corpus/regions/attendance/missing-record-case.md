# A day worked with no attendance record

An employee worked a full day but the attendance system shows nothing — no clock-in, no clock-out, not even a partial entry. There was no leave request for the day either, so the system defaults to showing it as unaccounted rather than as leave or absence.

The employee files the correction form checked "missing record," names the hours worked, and attaches supporting evidence: a same-day email thread and a calendar entry for a client meeting that afternoon. The line manager confirms the day was worked and signs the form.

Because the discrepancy was caught six days after the month closed, it falls inside the 10-day window from the correction deadline rule, so the fix reaches the same month's payslip on the adjusted run rather than carrying to the next one.

**A missing record is not treated as unauthorized absence by default, but it is not treated as a normal working day either until someone confirms it — an employee who assumes "no record means it's fine" and does nothing can find the day coded as absence once the window closes.** File the correction; don't wait for the system to fix itself.
