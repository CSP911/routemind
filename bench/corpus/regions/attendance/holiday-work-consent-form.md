# The consent form for holiday work

Working on a public holiday needs more than manager sign-off. Because it falls outside the ordinary working day entirely, it also needs the employee's own signed consent on file before the hours are worked.

## What it captures

The form records the date, the planned hours, the reason for the holiday work, and a signature from the employee agreeing to it — separate from whoever approves the overtime request itself.

| Requirement | Ordinary overtime | Holiday work |
|---|---|---|
| Manager approval | Required | Required |
| Employee signed consent | Not required | Required |
| Filed before hours worked | Yes | Yes |

Both documents are filed on the same deadline as the overtime request that covers the shift.

**An approved overtime request for a holiday date does not substitute for the consent form.** They are filed and checked separately, and the holiday premium is not released on payroll until both are on record — an approved request alone leaves the claim incomplete.

The exact hours that count as "holiday" for this purpose are set out in the night and holiday hours rule, not on this form.
