# Parental leave cases at a glance

Parental leave generates more edge cases than ordinary annual leave, because it touches eligibility, timing, team placement and insurance all at once. This page is the map; each row below is covered in full elsewhere.

## Where each scenario lives

| Scenario | Covered in |
|---|---|
| Both parents taking leave for the same child | parental-leave-both-parents-eligibility |
| Overlapping leave for the same child | parental-leave-overlap-case |
| Splitting leave into two blocks | parental-leave-two-block-split |
| Returning before the agreed end date | parental-leave-early-return-case |
| Extending an agreed block | parental-leave-extension-procedure |
| Returning to a changed team | parental-leave-team-reassignment-case |
| Insurance while on leave | parental-leave-insurance-coverage |

**The general childcare-leave eligibility and application order do not repeat here — this page assumes leave has already been approved and is about what happens during and around it**, not whether someone qualifies in the first place.

For eligibility and the order of application itself, start at childcare-leave.
