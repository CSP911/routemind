# Entitlement cases: what happens once entitlement is set

This half of the set picks up once service history is no longer in question and works through what the resulting entitlement actually does — proration for a mid-year joiner, the final balance for someone who leaves partway through the year, notifying an employee of the outcome, and what happens if none of that gets filed before the relevant deadline. Twelve cases, each ending in a specific number or a specific letter to the employee rather than a rule.

## The common case

Most of these come down to a proration calculation run off the join or leave date already confirmed in the service-history cases, checked against the balance at the point the case is opened, and confirmed back to the employee in writing. The number rarely changes once the underlying date is right.

## What goes wrong

**The trap is treating an unfiled entitlement case as a case that never happened.** It doesn't reset or disappear — it sits open, and the eventual correction is usually backdated to when it should have been filed, not to when someone noticed. File it as soon as the triggering event is confirmed, not once the balance is disputed.

The service-history half of this set is worth checking first if the join or leave date itself is in doubt.
