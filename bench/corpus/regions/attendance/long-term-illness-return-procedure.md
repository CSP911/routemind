# Returning from a long-term illness leave of absence

Once an illness has crossed the conversion point and moved onto the unpaid leave of absence track, coming back to work is not automatic on the day the employee feels ready.

## Before the return date

1. Give the HR desk **at least 14 days' notice** of the intended return date — the same notice period used for an early return from any other leave of absence.
2. Provide a fitness-for-work certificate confirming the employee is cleared to resume normal duties.

## What HR confirms on return

The HR desk checks the certificate, sets the return date in the attendance system, and reverts the pay and coding status from unpaid leave of absence back to active salary from that date forward.

**Turning up at the office on the planned return date without the certificate does not end the leave of absence — the unpaid coding stays in place until HR has something on file to close it.** An employee who simply resumes attending, assuming presence itself settles the matter, can find the days worked before the certificate arrives unpaid.

The 14-day window runs from the actual return date the employee proposes, not from whenever the illness happens to improve — plan the certificate before naming the date.
