# Approval routing for half and quarter-day requests

A half or quarter-day request goes through the same line-manager approval as a full day, but the request itself must specify which part of the day is being taken.

## What the request must contain

| Field | Required value |
|---|---|
| Unit | Half-day (AM/PM) or quarter-day |
| Time block | Morning, afternoon, or the specific quarter |
| Approver | Same line manager as full-day leave |

## Routing

The request is filed through the same attendance menu as a full day. The system flags it as fractional automatically once a half or quarter unit is selected — no separate form is needed.

**A half-day request submitted without specifying morning or afternoon is not defaulted to morning — it is returned to the requester unapproved, and no deduction happens until it is resubmitted correctly.**

Once approved, the fractional day is recorded and deducted exactly as set out in the half and quarter-day leave rule; this page only covers getting the request there.
