# Notice periods across a parental leave block

Four different moments inside a parental leave arrangement each carry their own notice requirement. None of them shortcut the others.

## The notice table

| Event | Notice required |
|---|---|
| Starting the leave | At least 30 days before the start date, agreed with the HR desk |
| Starting the second block | At least 30 days before that block's own start date |
| Extending the current block | At least 30 days before the original end date |
| Returning early | At least 14 days before the new return date |

## The trap

**The 30-day clock for a second block runs from that block's own start date, not from when the first block finished.** An employee who returns to work between blocks and then decides to start the second block sooner than planned still needs the full 30 days from that new date — finishing the first block early buys no head start on the second one.

None of these notice periods change what the leave actually pays out; for that, see how coverage during the leave itself is handled.
