# Who to notify for a same-morning leave request

An urgent request filed the same morning is only valid once it reaches the right person — a message to the wrong channel does not count as filed.

## The chain

1. Call or message the line manager directly.
2. Copy the HR desk group channel on the same message.
3. Once the line manager replies with approval, the request is entered retroactively into the attendance system.

## What does not count

A voicemail, a message left only in a personal chat with the line manager, or a note passed through a colleague does not start the approval clock.

**A same-morning request sent only to the line manager, without the HR desk channel copied, is not treated as filed — the attendance system still shows unapproved leave for that morning until HR confirms it separately.**

Once the entry is made, it is recorded and timed exactly as described in the same-morning leave rule; this page only covers who needs to see the message.
