# Where your service start date is recorded

## The field that drives everything

Every entitlement calculation — the first-year proration table, the 3/5/7-year milestone table, final settlement — reads from one service-start-date field in the HR system. Get this field wrong and every number downstream of it is wrong too.

## Who can change it

Only the HR desk can edit this field, and only against supporting documentation: a group transfer memo, a rehire bridging approval, or an entitlement correction request filed within its deadline.

## The trap

**You can see this field in the attendance system but cannot edit it yourself — if it looks wrong, that's a correction request, not a self-service fix.**

| Field | Editable by employee | Editable by HR desk |
|---|---|---|
| Service start date | No | Yes, with documentation |
| Leave balance | No | Yes |
| Leave requests | Yes | — |

Everything else in this section — transfers, rehires, milestones, final settlement — ultimately traces back to this one field.
