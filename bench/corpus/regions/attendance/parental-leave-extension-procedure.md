# Extending parental leave

## Steps

1. Decide the new end date before the original one arrives.
2. Submit the extension request to the HR desk **at least 30 days before the original end date**, not the new one.
3. HR confirms the extended date in writing and updates the attendance record.
4. The employee's manager is notified of the revised return date.

## Why the deadline is measured from the original date

**Counting the 30 days back from the new, later end date instead of the original one is the mistake that causes extensions to arrive late** — by the time the request reaches HR, the original leave has already ended and the employee is technically back at work with no cover in place.

## If the request is late

A late extension request is treated the same as a new parental leave application: it needs a fresh 30-day lead time from whenever it is actually submitted, and the gap between the original end date and the new start is unpaid leave outside the parental leave arrangement.

Compare this to the deadline for the leave itself, at leave-request-notice-table.
