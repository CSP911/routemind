# Attendance correction request form

One form covers all three correction types from the overview — missing record, duplicate record, disputed entry — with a checkbox at the top for which one applies. The rest of the form changes depending on that answer:

## Missing record
Date, expected hours, and the evidence used to reconstruct them (trip approval, overtime request, or a manager's confirmation).

## Duplicate record
Both entry timestamps as shown in the attendance system, and which one should be kept.

## Disputed entry
The record as currently logged, what it should say instead, and the team lead's name for the escalation step.

**Submitting the form without pulling the actual timestamps from the attendance system — relying on memory of "around 9" — is why disputed and duplicate cases get bounced back for resubmission.** Screenshot or export the record before filing, not after.
