# Entitlement case quick reference

Use this to check which case applies before doing arithmetic by hand.

## Event effects

| Event | Service-start-date | Accrual for the year |
|---|---|---|
| Documented group transfer | preserved | continues unbroken |
| Transfer filed as resign + rehire | reset | starts at day one |
| Rehire, short gap | preserved | continues unbroken |
| Rehire, long gap | reset | starts at day one |
| Leave of absence, any length | unaffected | prorated for time worked |
| 3/5/7-year anniversary | unchanged | +1 day from the anniversary date |
| Resignation | closes | prorated to last day worked, then paid out |

## The trap

**None of these are decided by guesswork or by what the profile screen displays — every row above is read from a single field, and two people looking at the same employee can disagree about which row applies if one of them is looking at the wrong source.** When a figure looks wrong, check the field before checking the arithmetic.

If the field itself needs correcting, there is a window for that, and it closes.
