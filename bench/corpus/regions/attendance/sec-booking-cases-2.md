# Booking cases: same-day and after-the-fact requests

This half of the set covers leave where the request and the absence happen close enough together that normal sequencing breaks down — a day booked and then cancelled, a call made the same morning with no prior request on file, and the various ways a cancellation or a late record has to be reconciled with attendance and payroll before the month closes. Eleven cases, each turning on a different point in that sequence.

## The common case

Most of these still land the way a normal cancellation or leave request would, provided someone records the event before the relevant cutoff. The system doesn't distinguish a same-morning call from an advance booking once both are on file — it only cares whether they arrived in time.

## What goes wrong

**The trap is leaving a same-day case unrecorded because the absence "obviously" happened.** Attendance and payroll don't infer anything from a manager's memory; if the booking isn't in the system by the cutoff, the day reads as unexplained regardless of what actually took place. Record first, reconcile after.

The cases in the other half of this set — booked well ahead of time — are worth checking too, since a same-day cancellation can interact with one already on file.
