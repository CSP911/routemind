# Evidence checklist for an entitlement case

## What HR needs on file
| Case type | Document required |
|---|---|
| Group transfer | Transfer letter from the originating affiliate confirming the join date there |
| Rehire | Prior employment record and the offer letter for the new start |
| Leave of absence | The approved LOA form with start and end dates |
| 3/5/7-year milestone | None — reads directly from the service-start date |
| Final balance (leaver) | Resignation date and the usage log for the current leave year |

## The trap
**A case with no evidence on file is not held open — it is treated as if the event never happened.** An employee who transferred from a group affiliate but never had the transfer letter filed will be entered as a new joiner, on 15 days flat, with no route to appeal once the leave year closes. The facts of the move don't matter if the paperwork isn't in the system before then.

Get the evidence to the HR desk as soon as the event happens, not when the balance looks wrong months later — by then the year may already be closed, and a correction request only reopens a wrong count, not a missing case.
