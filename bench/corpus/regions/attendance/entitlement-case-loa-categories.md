# Leave types that count as continuity-preserving leave of absence

## Categories
| Leave of absence type | Counts toward service years |
|---|---|
| Childcare leave | Yes |
| Statutory military service | Yes |
| Approved medical leave | Yes |
| Unauthorised or unapproved absence | No |

## The trap
The rule that keeps the service clock running through a leave of absence only applies to leave that was **approved through the HR desk before it started** — not to any period an employee happens to be away from work. **Time spent on an absence that was never formally approved does not count toward the 3/5/7-year ladder, even if it's later explained and excused.** The distinction isn't about whether the absence was reasonable; it's about whether it was on file as approved leave of absence at the time it occurred.

If a milestone date falls inside a leave period, confirm which category it was filed under before assuming the anniversary still counts — the worked example for an anniversary landing during leave only holds for the approved kind.
