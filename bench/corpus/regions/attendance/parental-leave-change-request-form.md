# The parental leave change request form

Any change to an already-agreed parental leave block — extending it, ending it early, or opening a second block — goes through one form, submitted to the HR desk rather than through a manager's approval alone.

## What it captures

| Field | Purpose |
|---|---|
| Current block dates | What is already on record |
| Requested change | Extension, early return, or new block |
| New effective date | Must respect the applicable notice period |
| Manager acknowledgement | Confirms staffing awareness, not approval authority |

## The trap

**This form is not the general leave amendment form.** The form used to cancel or shorten an ordinary booked leave day does not carry parental leave through the eligibility and notice checks this one does — using the wrong form gets the request logged against the wrong leave type entirely and the notice clock never starts.

The eligibility check behind this form is the same one applied when the leave is first agreed, before either parent's block begins.
