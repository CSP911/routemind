# Notice periods by request type

## The table
| Request type | Expected notice |
|---|---|
| Full day, planned | As early as practical; no fixed minimum, but same-day is discouraged unless urgent |
| Half day / quarter day | Same as a full day — no shorter minimum for a smaller unit |
| Same-morning (urgent) | Manager contacted before start of day; system entry by end of day |
| Leave spanning year-end | December and January days booked separately; the January request only once the new balance posts |
| Parental leave | At least 30 days before the leave starts, agreed with the HR desk |

## The trap
**Notice periods here are expectations, not hard deadlines that block submission — the leave system will accept a same-day full-day request just as it accepts one booked weeks ahead.** The only genuinely enforced minimum is the 30-day parental leave notice; everything else depends on manager discretion and whether the balance and business need allow it.

Shorter units do not buy a shorter notice period, and a longer block does not require a longer one either — what actually blocks a request is balance, not timing.
