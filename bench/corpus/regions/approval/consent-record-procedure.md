# How consent gets recorded in the draft

Consent that lives only in an email thread or a hallway conversation does not survive a file check. It has to be attached to the draft in the same place the approver's signature goes.

## Steps

1. The drafter identifies which teams have to consent, based on the draft's kind.
2. Each consenting team responds in writing — either on the draft form itself or as an attached note — stating consent, objection, or no comment.
3. The drafter attaches every response before routing the draft to the approver.
4. If a response never arrives within the window, the drafter logs "no response received," not "consent given."
5. The completed file, with consent responses attached, is filed under the retention period the draft's kind carries — five years for most drafts, ten for contracts.

## What gets missed

**A verbal "that's fine" from a consenting team's lead is not consent on file — if it isn't attached to the draft, the draft is treated as if consent was never sought at all.**

Where the completed file with its attachments actually goes to be kept is a separate question from who has to sign it.
