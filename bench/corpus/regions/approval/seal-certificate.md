# Requesting a seal certificate

A seal certificate confirms that an impression on a document matches the seal registered with the relevant authority. Contracts, property dealings, and most bank transactions involving the corporate seal require one attached to the file, not just the impression itself.

## Certificate types

| Certificate type | Purpose stated on request | Typical use |
| --- | --- | --- |
| General-purpose | None | Bank account opening, general internal filings |
| Purpose-limited | Named transaction | Contracts, property transactions, one-off external filings |

## Requesting one

State the seal being certified, the transaction it supports, and the recipient the certificate goes to. Purpose-limited certificates are matched to a single draft in the file, not to the counterparty in general.

**A purpose-limited certificate issued for one contract cannot be reused for the next one — request a fresh certificate for each transaction, even if the counterparty is the same and the last certificate has not expired.** A certificate that does not match the transaction it is attached to is treated on review as if none had been attached at all.

Where the document is going overseas, the certificate alone is rarely enough.
