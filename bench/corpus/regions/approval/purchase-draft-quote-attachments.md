# What a purchase draft attaches

The draft form has a text field for describing the purchase and a separate attachment slot for the evidence behind it. Reviewers are expected to check the attachments, not take the drafter's summary on faith.

## Required attachments

| Field | Required for |
|---|---|
| Quotes, one per vendor named | All purchases, per the quote count table |
| Scope or spec note | All purchases, so quotes can be checked for comparability |
| Budget code | All purchases |
| Expected effect | 3,000,000 KRW and over |

## The trap

**A drafter who types "quote received, 2,400,000 KRW from Vendor A" into the description field has not attached a quote.** The reviewer has no document to check the price, the date, or the scope against. If the attachment slot is empty, the draft has to be returned regardless of how detailed the text description is.

This is also the field a consenting team checks first when they're asked to sign off on budget grounds — an empty attachment slot is usually where an objection starts.
