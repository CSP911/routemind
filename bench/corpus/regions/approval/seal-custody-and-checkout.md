# Seal custody and checkout

Doc-admin holds both the company seal and the corporate seal in locked custody. Neither seal leaves the cabinet without a checkout entry tied to a specific draft.

## What gets logged

| Field | Recorded at checkout |
| --- | --- |
| Seal | Company or corporate |
| Draft reference | The document the seal is being applied to |
| Requested by | Drafter or approver name |
| Checked out / returned | Date and time both ways |

## The trap

**Checking out the corporate seal for one contract does not authorise using it again the same afternoon for a second document.** Each checkout is matched to a single draft; a second use needs its own entry, even if the same person is holding the seal and the second document is on the same desk. A checkout log with one entry covering two documents reads, on later review, as a seal used without authorisation for whichever document is not named on it.

The same principle sits behind the destruction log for retired documents — one entry, one action, no exceptions for convenience.
