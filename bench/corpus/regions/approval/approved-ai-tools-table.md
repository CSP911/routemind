# Approved AI tools by use case

The same product can appear twice on this list — once approved, once not — because the enterprise tier and the consumer tier are different products for this purpose even when the name is identical.

| Use case | Status | Notes |
|---|---|---|
| General drafting or summarizing of public text | Approved (enterprise tier only) | No personal data, no unpublished figures |
| Code assistance on internal repositories | Approved (enterprise tier only) | Repository access confirmed non-training by IT |
| Translation of external correspondence | Approved (enterprise tier only) | Consumer tier of the same tool is not approved |
| Analysis of spend, HR, or customer records | Not approved | Case-by-case only, with Legal and IT consent |
| Any free or consumer tier, of any tool above | Not approved | Retains input for training regardless of the enterprise entry |

**The enterprise line item does not cover the consumer version of that tool** — a subscription bought outside IT's procurement does not inherit the enterprise terms just because the interface looks the same.

Adding something not on this list follows its own approval steps, not a request to update this table directly.
