# What the trip claim system assumes about overseas bands

## What it fills in
When an overseas trip claim is opened, the system reads the approved itinerary and assigns each night a band automatically, pulling the lodging cap and daily allowance from that band's row in the table. For a single-country trip this is usually correct without any manual entry.

## Where it gets it wrong
The automatic assignment is built for one country per trip. It does not split a multi-country itinerary by night on its own — it assigns the whole trip to the band of the first destination listed, and every later country has to be entered manually to correct the split. The same gap applies to a stopover that earns its own band: the system will not add that night unless it is entered as a separate line.

## The trap
**Filing a multi-country or stopover claim without correcting the system's single-band default carries the first country's rate through the whole trip**, usually to the traveller's disadvantage if the first leg is the cheaper band, and to the company's if it is the more expensive one. Either way it does not match the itinerary and gets kicked back.

A mid-trip band change has to be entered the same way, from the date the change took effect, not assumed from the original booking.
