# Translation and foreign-language receipts

## What has to be readable
A receipt in another script is accepted once it is converted using the transaction date's exchange rate, exactly as with any overseas spend. The merchant name, the date and the amount are what the approver needs to identify — nothing else has to be in Korean.

## When a translation helps and when it doesn't
For a long invoice with itemised lines, a short translation note attached alongside the original speeds up approval. **The translation is a convenience, not a substitute — the original receipt still has to be attached, and a translation without the source document is treated as no evidence at all.**

## Who signs off
The approver reviewing the claim decides whether the receipt is legible enough to identify the three required fields. If it isn't — a faded thermal receipt, a heavily stylised regional script — treat it the same as a receipt that can't be produced, and file a statement of the circumstances instead.

This is the same fallback used when a merchant overseas has already closed and cannot reissue anything at all.
