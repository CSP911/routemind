# Currency by leg on a multi-country claim

## One rate per charge, not one rate per trip

A multi-country itinerary does not settle at a single blended rate. Every charge converts using the transaction date's exchange rate shown on the card statement — the same rule that applies to any foreign-currency spend — regardless of how many countries the trip touches or in what order.

| Leg | Currency | Rate source |
|---|---|---|
| Outbound nights, country A | Local currency A | Card statement rate, date of that charge |
| Middle nights, country B | Local currency B | Card statement rate, date of that charge |
| Return nights, country A | Local currency A | Card statement rate, date of that charge |

## The trap

**Returning to a country you already visited earlier in the trip does not mean the return-leg charges reuse the earlier rate.** Each charge is converted on its own date, so the same currency can legitimately convert at two different figures within one claim if the market moved in between.

Which band each of those return nights falls into is a separate question, decided the same way as any other re-entry into a previously visited country.
