# VAT-exempt sellers

## What they can issue
Some sellers — tutoring services, certain medical providers, some financial services — are exempt from VAT and issue a tax-exemption receipt instead of a standard tax invoice. This counts as qualifying evidence provided it shows the business registration number and the amount.

## The trap
**Being VAT-exempt does not raise the 30,000 KRW threshold or waive the need for qualifying evidence.** A tax-exemption receipt above 30,000 KRW is required in exactly the same cases a tax invoice would be; a simple receipt from the same seller is not a substitute.

## Common cases
| Seller type | Document to ask for |
|---|---|
| Tutoring or lecture fee | Tax-exemption receipt |
| Medical service | Tax-exemption receipt or medical receipt with registration number |
| Some financial services | Statement or invoice from the provider |

If the seller's own document instead carries someone else's name — a shared booking, a colleague's account — that's a different trap.
