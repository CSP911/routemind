# Evidence in awkward cases, at a glance

## Quick reference
| Situation | What to do |
|---|---|
| Foreign-language receipt | Accept as-is with a short note; convert at the statement's exchange rate |
| E-receipt lost | Ask the merchant to resend; file a statement for reissue if they can't (3–5 working days) |
| Merchant can't issue a tax invoice | Disbursement form up to ~100,000 KRW; qualifying evidence required above it |
| VAT-exempt seller | Tax-exemption receipt above 30,000 KRW, same as a tax invoice |
| Receipt in someone else's name | Rejected — have the actual payer file the claim |
| Split payments at one merchant | Treated as one spend by merchant and date |
| Refund after filing | Report within 5 working days; offset at next settlement |

## The one rule underneath all of these
**None of these situations move the 30,000 KRW line or replace the need for qualifying evidence — they only change which document satisfies it.** When a case doesn't fit the table, treat it as no qualifying evidence at all and expect the 2% penalty unless accounting agrees otherwise in advance.

For the baseline rule these all sit on top of, see what counts as evidence in the ordinary case.
