# Virtual card numbers by vendor type

A single-use virtual number is generated per transaction and closes after that transaction clears, rather than staying open the way a prepaid card's own number does.

## When each is used

| Vendor type | Card used |
|---|---|
| One-off online purchase, unfamiliar seller | Single-use virtual number |
| Recurring subscription | Standing prepaid or corporate card number |
| Overseas online vendor with no Korean presence | Single-use virtual number |
| Vendor already on the approved list | Standing prepaid card number |

## Why the split matters
A single-use number can't be charged twice — a vendor's retry, on a failed payment or a delayed shipment, is declined and looks like a bank error rather than a billing problem. **If a vendor might need to charge again — a split shipment, a deposit followed by balance — using a single-use number for the first charge blocks the second one outright**, and the fix is a fresh number, not a call to the bank.

## Requesting a number
Numbers are generated through the same portal as a top-up request, tied to a specific merchant name and ceiling amount before the purchase.

A spent single-use number carries no balance forward — that only exists on the standing prepaid card.
