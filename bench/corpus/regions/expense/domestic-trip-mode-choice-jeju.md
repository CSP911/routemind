# A Jeju trip books air by default

The mode-choice rule that keeps a Seoul–Daegu leg on rail assumes rail is an option in the first place. Jeju has none. There is no marginal comparison to make, no fare table to run, and no sign-off needed on the grounds that air was chosen over rail — air is simply the only way to get there.

## What still needs approval

Removing the mode question doesn't remove the class question. Economy is the standard fare for the route, and the trip is approved and claimed like any other domestic trip: fare, lodging by city tier, daily allowance.

**Economy is the default precisely because air is mandatory here — booking business class still needs the same team lead sign-off a business-class upgrade would need on a marginal mainland leg.** Travellers sometimes read "air is fine for Jeju" as "any fare class is fine for Jeju." It isn't; the exemption is from the rail comparison, not from the fare-class rule.

Everything downstream — lodging by city, the daily allowance — runs exactly as it would for a mainland trip. See the mode-choice worked example for how a marginal leg on the mainland is judged differently.
