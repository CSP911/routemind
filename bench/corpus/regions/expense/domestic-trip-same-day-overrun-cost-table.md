# What changes in the budget when a same-day trip runs long

| Item | Planned as same-day | Converted to overnight |
|---|---|---|
| Fare | Actual cost | Actual cost, unchanged |
| Daily allowance | 20,000 KRW, one day | 20,000 KRW, per day — a second day is added |
| Lodging | None | Actual cost, up to the city's cap (80,000 or 100,000 in Seoul and Busan) |

The fare line doesn't move regardless of which way the trip is filed — it was always going to cost what it cost. What changes is that a second day's allowance is unlocked, and a lodging line becomes claimable for the first time.

**The extra allowance is a second day at the same flat rate, not the original day's rate doubled.** A claim that shows 40,000 KRW against a single day, rather than 20,000 KRW against each of two days, gets sent back even though the total looks identical, because the system books allowance by calendar day.

The overrun has to be resubmitted as an overnight claim before filing, and the approver needs notice of the change before that happens — see the resubmission and deadline documents for that sequence.
