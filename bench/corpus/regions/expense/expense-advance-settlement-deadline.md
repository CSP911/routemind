# Settling a cash advance after the trip

Drawing an advance is the easy part. It has to be closed out against actual spend once the trip or purchase is done.

## The window

- Settle within **7 working days** of return or of the purchase being complete.
- Submit actual receipts against the advance amount; qualifying evidence still applies above 30,000 KRW on each line, exactly as it would on a card claim.
- Any unspent balance is returned at settlement. Any shortfall is reimbursed the same way a personal-card charge would be.

## The trap

**An advance not settled inside the window is not simply chased later — it is deducted from the next payroll run as an outstanding balance.** This happens automatically once the window closes; there is no separate warning stage. Someone who travels again before settling the first advance will usually find the second request blocked until the first is closed.
