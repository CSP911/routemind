# Variance thresholds

Not every gap between budget and actual needs a note, and not every note can go in without sign-off. The bands below apply per line, not per cost-centre total.

| Variance | What's required |
|---|---|
| Within 10% and under 2,000,000 KRW | No explanation needed |
| Over 10% or over 2,000,000 KRW | Written explanation required |
| Over 20% or over 5,000,000 KRW | **Division head sign-off required before submission** |

Both the percentage and the absolute KRW figure are checked, and whichever is crossed first applies. A 5% move on a large line can still cross the 2,000,000 KRW mark long before it reaches 10%, and a small line can swing 30% on a rounding difference without ever reaching the KRW threshold.

**A line that nets to zero because an overrun on one item offset an underspend on another still has to be explained if either side crossed the threshold on its own.** The report checks lines, not totals.

Explanations that pass this check still have to name a cause, not just the number — covered in how the report itself is prepared.
