# What the variance report fills in for you

## Automatic
The monthly report pulls actuals directly from the card feed and filed trip claims — no one re-enters a spend figure by hand. The budget figure it compares against is the annual split for that line, or the latest approved reforecast if one is in effect. The variance percentage is calculated from those two numbers the moment the actuals feed lands.

## Manual
Anything past that is typed in by a person: the cause narrative for a line inside an explanation band, the corrective note, and the sign-off field for a line that crosses into division-head territory.

**The system computes variance against the original annual split until a reforecast is actually approved — a submitted-but-unapproved reforecast changes nothing on screen.** A team that assumes the new number is already live and stops explaining the gap will find the report still flags the old variance.

## Where it can go wrong
A claim tagged to the wrong line item feeds the wrong actuals figure automatically; the system has no way to know the tag was wrong, so the variance it shows is only as good as the tagging done at claim submission.

That tagging is the same one covered under budget line items.
