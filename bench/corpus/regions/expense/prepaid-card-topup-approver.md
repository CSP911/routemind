# Who signs off a prepaid card top-up

A top-up request goes back to the same approver who signed off the card's original issuance, not to whichever manager happens to be available. That approver set the initial amount and is the one who can tell whether running out means the estimate was wrong or the spend has grown.

## Where it splits
- **Original approver**: confirms the top-up amount and purpose still match the card's stated use
- **Finance**: loads the funds once approved, and checks the card hasn't already hit its two-top-up limit
- **Division head**: only involved if the cumulative amount across issuance and top-ups crosses the same threshold that would require their sign-off on a normal expense claim

## The trap
**A different manager approving a top-up because the original approver is on leave doesn't hold** — finance bounces the request back and asks for the original approver's sign-off, or an explicit written delegation naming them, before loading anything.

If the card was issued for one project and the top-up is really for a different one, that's a new card, not a top-up — issuance criteria apply again from the start.
