# Approval threshold, 2024-07-01 to 2025-12-31

## The version this was
In force from **2024-07-01** until **2025-12-31**. It is **not current** — from 2026-01-01 the table in
`sec-hard-threshold` applies, which adds term as a third qualifier. Before 2024-07-01 the rule
was the one in `threshold-table`, which had neither category nor term.

Use this one, and only this one, for anything dated between 2024-07-01 and 2025-12-31.
