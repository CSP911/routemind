# Leave accrual, type E3, tenure T1, site L4

## Who this row covers
Type e3, tenure t1, site l4. The three qualifiers are what select this row; see the legends if you
are not sure which values apply to you.

| | |
|---|---|
| Accrues per month, days | 1.10 |
| Carry-over limit, days | 7 |
| Notice required, working days | 4 |
| Accrues during unpaid leave | no |

*In force from 2026-01-01. The version before this one (2024-07-01 to 2025-12-31) is `hard-accrual-v2`; before that, `leave-accrual`. See `hard-accrual-legend-revision`.*

## If the figures are exceeded
An excess that was not approved in advance is settled at the figure above and the difference is not
recoverable. An unavoidable excess is claimed with a short written statement and the evidence, and
is decided by the budget holder rather than by this table.
