# Overtime rate, day D4, hours H1, place P1

## Who this row covers
Day d4, hours h1, place p1. The three qualifiers are what select this row; see the legends if you
are not sure which values apply to you.

| | |
|---|---|
| Multiplier | 2.64x |
| Rounding | to the nearest 5 minutes |
| Approval needed in advance | yes |
| Counts toward the monthly cap | no |

*In force from 2026-01-01. The version before this one (2024-07-01 to 2025-12-31) is `hard-overtime-v2`; before that, `overtime-rate-table`. See `hard-overtime-legend-revision`.*

## If the figures are exceeded
An excess that was not approved in advance is settled at the figure above and the difference is not
recoverable. An unavoidable excess is claimed with a short written statement and the evidence, and
is decided by the budget holder rather than by this table.
