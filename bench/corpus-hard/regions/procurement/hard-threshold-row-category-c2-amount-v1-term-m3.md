# Approval threshold, category C2, amount V1, term M3

## Who this row covers
Category c2, amount v1, term m3. The three qualifiers are what select this row; see the legends if you
are not sure which values apply to you.

| | |
|---|---|
| Delegation limit | 1018 thousand KRW |
| Signs it off | the department head |
| Competing quotes | none |
| Working days to expect | 4 |

*In force from 2026-01-01. The version before this one (2024-07-01 to 2025-12-31) is `hard-threshold-v2`; before that, `threshold-table`. See `hard-threshold-legend-revision`.*

## If the figures are exceeded
An excess that was not approved in advance is settled at the figure above and the difference is not
recoverable. An unavoidable excess is claimed with a short written statement and the evidence, and
is decided by the budget holder rather than by this table.
