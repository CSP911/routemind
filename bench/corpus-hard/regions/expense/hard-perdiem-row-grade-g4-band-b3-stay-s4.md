# Overseas per-diem, grade G4, band B3, stay S4

## Who this row covers
Grade g4, band b3, stay s4. The three qualifiers are what select this row; see the legends if you
are not sure which values apply to you.

| | |
|---|---|
| Lodging, per night | 331 USD |
| Meals, per day | 108 USD |
| Receipt threshold | 57 USD |
| Incidentals, per day | 22 USD |

*In force from 2026-01-01. The version before this one (2024-07-01 to 2025-12-31) is `hard-perdiem-v2`; before that, `overseas-rates`. See `hard-perdiem-legend-revision`.*

## If the figures are exceeded
An excess that was not approved in advance is settled at the figure above and the difference is not
recoverable. An unavoidable excess is claimed with a short written statement and the evidence, and
is decided by the budget holder rather than by this table.
